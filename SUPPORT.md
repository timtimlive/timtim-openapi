# Getting help

These projects are a **Developer Preview**. Here is where to go:

| You want to… | Go here |
|---|---|
| See it work first | https://timtim.live/developers/demo |
| Get started in 60 seconds | https://timtim.live/developers/quickstart |
| Read the documentation | https://timtim.live/developers/docs |
| Try things safely (test keys, sample events) | https://timtim.live/developers/sandbox |
| Get a key | https://timtim.live/developers |
| Ask a question or share what you built | https://timtim.live/developers/community |
| Check whether the API is up | https://timtim.live/developers/status |
| Report a bug in the code | An issue in the repository (use the **Bug report** form) |
| Report a security problem | **Privately**: "Report a vulnerability" on the repository's Security tab — never a public issue. Policy: https://timtim.live/partners/security |
| Talk about a business partnership | https://timtim.live/partners or bookings@timtim.live |
| Ask about personal data | privacy@timtim.live |

When you ask about an API call, include the `request_id` from the error (or the `TimTim-Request-Id` header). Never paste a key.
